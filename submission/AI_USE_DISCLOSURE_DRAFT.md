# Draft AI-use disclosure for human review

Devin, an artificial-intelligence software engineering system developed by
Cognition AI, was used to implement and test simulation code, retrieve and
organize public source metadata, execute prespecified analyses, generate
code-derived figures and tables, and prepare a factual authoring packet. The AI
did not create or alter empirical source data and is not an author. Human
authors must independently inspect the code, source snapshots, analysis
registry, citations, figures, tables, and all proposed prose; determine the
scientific interpretation and conclusions; revise the final manuscript in
their own expert voice; and accept responsibility for the submitted work.

Before submission, the authors should add the exact Devin model/product version
available in their account records, confirm that this statement matches actual
subsequent use, and place it in the location required by the current Wiley and
Conservation Biology submission interface.
