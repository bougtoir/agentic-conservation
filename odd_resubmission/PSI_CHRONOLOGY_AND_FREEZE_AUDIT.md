## Freeze audit findings
1. **The holdout design was frozen before launch**, and no outcome was inspected before 03:26:24. This part of the protocol held.
2. **The documented frozen model was not the evaluated model.** The freeze file says MBP = 8 (dev 0.896). The holdout Ψ was generated by V0 with MBP = 4, a state whose development accuracy was **0.608**. This value was observed 3.5 minutes before launch.
3. **The committed model (V1) was never evaluated on the holdout in the original work.** It was edited after the launch but before any holdout outcome was seen. The edits were triggered by a unit-test failure, not by holdout data. V1 was then reported with the V0 holdout results.
4. The manuscript's dev figures (0.888 / 0.910) and holdout figures (0.393 / 0.846 / 0.045) therefore come from **two different model versions**, and neither uses the documented MBP = 8.
5. MBP = 8 was selected on development data but never applied to the holdout run or to the committed code.
